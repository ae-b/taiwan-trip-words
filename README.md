# 台湾旅行フレーズ帳

台湾旅行でよく使うフレーズ・単語をまとめた、スマホ向けの単語カードアプリです。

🔗 https://ae-b.github.io/taiwan-trip-words/

## 特徴

- 日本語 / 中国語(台湾) / 英語を切り替え表示、ピンイン・カタカナ読み付き
- カテゴリ別の単語カードで学習、覚えた状態を記録
- タップでめくる、スワイプで移動、音声読み上げにも対応

## 使い方

上記URLをスマホのブラウザで開き、「ホーム画面に追加」しておくとアプリのように起動できます。

## 更新方法

`index.html` を編集して `main` ブランチにpushすると、GitHub Pagesに自動反映されます。

## 技術構成

- 依存ライブラリなしの単一HTMLファイル(バニラJS)
- Google Fonts(Noto Serif TC / Noto Sans TC / JetBrains Mono)を使用
